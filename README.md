# TerraSpectra: Hyperspectral Crop Disease Forecasting

## Project Overview
TerraSpectra is an individual Data Science and Machine Learning project developed as part of the Infotact Solutions internship.

The project focuses on analyzing hyperspectral crop data to study disease-related patterns and develop machine learning approaches for crop disease forecasting.

## Project Details
- **Internship Organization:** Infotact Solutions
- **Role:** Data Associate L1 Intern
- **Domain:** Data Science and Machine Learning
- **Project Duration:** 10 November 2026 – 10 December 2026
- **Project Type:** Individual Project

## Project Objectives
- Collect relevant hyperspectral agricultural datasets.
- Perform data preprocessing and cleaning.
- Conduct Exploratory Data Analysis (EDA).
- Develop Machine Learning models.
- Evaluate model performance.
- Document findings and results.

## Technology Stack
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook
- Git and GitHub

## Project Structure
- `data/` – Dataset storage.
- `notebooks/` – Data analysis and experiments.
- `src/` – Python source code.
- `models/` – Trained models.
- `results/` – Graphs and predictions.
- `reports/` – Project documentation.
